Capítulo 1

Etiquetas HTML

Para comezar a crear as nosas paxinas web o unico que temos que facer e ir compoñendo as diferentes etiquetas HTML dun documento. Unha etiqueta HTML é un termo rodeado por un signo de menor e outro de maior.

Estrutura básica dunha paxina

As paxinas web manteñen unha estrutura moi sinxela que debemos respetar para que os navegadores sexan capaces de presentala. Non podemos comezar a nosa paxina cunha etiqueta de párrafo, por exemplo, senon que debemos indicar que tipo de páxina estamos xerando, que información adicional levará e onde comeza o contido que debe ser amosado.

Capitulo 2

Párrafos e Títulos

A linguaxe HTML é moi coidadosa coa organización da información, polo que o primeiro que debemos coñecer é como estruturar os títulos e como definir os parrafos de texto.

Párrafos

As etiquetas p y /p empreganse para definir un bloque de texto que se comporta como un parrafo. Normalmente non deixaremos nunca unha porción de texto solta pola paxina web, senón que a rodearemos con esas etiquetas.

Títulos

As etiquetas desde (hl a b5) utilizanse para definir un texto como titulo, indicando que é unha cabeceira que queremos destacar sobre o resto do texto. Tenemos 6 opcións para definir diferentes títulos de maior a menor importancia.
